# Lambda

This folder is reserved for future AWS Lambda functions supporting the Claim-to-Policy Matching Assistant.

Potential Lambda functions may include:

- retrieve_relevant_policies
- compare_claim_to_policy
- detect_missing_information
- generate_policy_summary
- generate_analyst_brief

These functions may later integrate with:

- Amazon Bedrock
- Bedrock Knowledge Bases
- API Gateway
- DynamoDB
- EventBridge
