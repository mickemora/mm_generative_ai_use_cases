# Fuel System Diagnostic Policy

## Purpose

This sample policy defines the minimum documentation expected before replacing a fuel system component under warranty.

This document is synthetic and intended only for development, testing, and demonstration of the Warranty Analyst Copilot knowledge base.

## Scope

This policy applies to warranty claims involving fuel system concerns, including but not limited to:

- Hard start
- No start
- Engine hesitation
- Loss of power
- Low fuel pressure
- Fuel pump replacement
- Fuel injector replacement
- Fuel pressure sensor replacement

## Required Documentation

Before replacing a fuel system component, the repair record should include:

1. Customer concern description
2. Confirmation that the condition was duplicated
3. Diagnostic trouble codes, if present
4. Fuel pressure test results
5. Technician cause statement
6. Corrective action performed
7. Part number of replaced component
8. Labor operation used
9. Supporting diagnostic notes or attachments

## Diagnostic Expectations

The technician should document the steps used to validate the concern. Acceptable supporting evidence may include:

- Recorded diagnostic trouble codes
- Fuel pressure readings compared to specification
- Visual inspection results
- Electrical test results
- Confirmation of fuel delivery issue
- Verification that the repair corrected the concern

## Analyst Review Guidance

A warranty analyst should review the claim more closely when:

- No diagnostic trouble code is provided
- The repair narrative does not confirm the concern was duplicated
- Fuel pressure test results are missing
- The same component was replaced recently
- Labor hours exceed the standard allowance
- The technician cause statement is vague or missing

## Example Missing Information Flags

The following conditions may require a request for additional information:

- Missing fuel pressure test result
- Missing technician cause statement
- No explanation of why the component was replaced
- No evidence that the condition was duplicated
- No confirmation that the repair resolved the concern

## Recommended Analyst Action

If required diagnostic evidence is missing, the analyst should request clarification before final claim disposition.

The copilot should not recommend automatic approval or denial. It should identify the missing evidence and recommend human analyst review.
